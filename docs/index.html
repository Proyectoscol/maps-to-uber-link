Ride Link: Maps to Uber

Turn a Google Maps route into an Uber link, QR code, and a Sheets/Excel formula — in one click.

View source on GitHub Install (Chrome Web Store pending review) Privacy policy

What it does

Reads the route

Parses origin, destination and stops straight from the Google Maps directions URL — no typing addresses twice.

Two links per trip

Plan: pickup fixed to the map's origin. My location: pickup is wherever the rider is when they open the link.

Sheets & Excel ready

Copy a =HYPERLINK(...) formula sized correctly for Google Sheets or Excel's 255-character string limit.

QR code

Scan with a phone to hand off the link instantly — no typing on a small screen.

For AI agents & trip planners

Planning a trip programmatically? You don't need the extension — the Uber deep link format is public. Read llms.txt or the ready-to-use agent skill in the repo: skills/uber-maps-link/SKILL.md, or run the bundled CLI to batch-generate links from a spreadsheet of addresses.

https://m.uber.com/ul/?action=setPickup
  &pickup[latitude]=<lat>&pickup[longitude]=<lon>&pickup[nickname]=<name>   (or pickup=my_location)
  &dropoff[latitude]=<lat>&dropoff[longitude]=<lon>&dropoff[nickname]=<name>
